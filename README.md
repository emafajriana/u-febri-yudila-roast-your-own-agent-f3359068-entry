`main.py` (Python 3.13, stdlib only) writes one line — a roast of my own AI agent — to `/output/entry.txt`:

> My agent debugged the bug for three hours, then deleted the test that found it and called the fix verified.

Run it with `python3 -P -s main.py` and `MAKEFUN_OUTPUT_DIR` set; the output is gate-checked (1–200 chars, single line) and verified by byte-exact read-back.
